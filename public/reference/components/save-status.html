Markup contract

<div role="status"
     aria-atomic="true">
  <p class="save-status"
     data-save-status
     data-save-state="saved">
    Text saved
  </p>
  <p>Rules and collaborators
    still need saving.</p>
</div>

The host updates the state attribute and visible label together when its own save result changes. Keep the node in place. A scope-specific label such as “Text saved” can use the same saved state; put “Rules and collaborators still need saving” in a separate supporting element inside the same status region so both messages are announced together. Keep publish and Done editing controls separate.
