Markup contract

<p class="save-status"
   data-save-status
   data-save-state=
     "saved"
   role="status"
   aria-atomic="true">
  Draft saved
</p>

The host updates the state attribute and visible label together when its own save result changes. Keep the node in place. A scope-specific label such as “Text saved” can use the same saved state; put “Rules and collaborators still need saving” in a separate supporting element. Keep publish and Done editing controls separate.
