Copy button – Reference – Live Wires

Copy button

The button reports success only after the browser confirms a clipboard write. The read-only text remains visible and selectable if permission is denied or clipboard access is unavailable.

Markup contract

<script type="module" src="/dist/copy-button.js"></script>

<lw-copy>
  <label for="share-address">Share address</label>
  <textarea id="share-address" data-copy-source rows="2" readonly>https://example.test/meeting/annual-planning</textarea>
  <button type="button" data-copy-button>Copy address</button>
  <p data-copy-status role="status" aria-live="polite" aria-atomic="true"></p>
</lw-copy>

Each instance owns its source, button, and live status. On failure, focus stays on the button and the message tells people to select the text field and use their device's copy command. No default runtime or server clipboard policy is changed.
