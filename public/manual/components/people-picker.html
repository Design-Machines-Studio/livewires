Using the picker

Use a fieldset and legend to name the picker. Keep each checkbox’s name and detail separate with aria-labelledby and aria-describedby. Use the existing avatar component; its image or initials are decorative beside a visible name. Your application handles group membership, permissions and saving, and preserves locked values because disabled inputs are not submitted.
