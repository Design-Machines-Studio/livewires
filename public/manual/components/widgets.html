Unboxed metrics

A standalone metric is a definition list. Groups use dl.widget-metrics with div.widget-metric groups, each containing its own dt and dd. Numeric values appear above labels visually, while terms remain first in the semantic DOM.

<dl class="widget-metric">
  <dt>Active</dt>
  <dd class="widget-metric-value font-metric tnum"
      style="--widget-metric-size: var(--text-4xl);
             --widget-metric-weight: 650;
             --widget-metric-width: 80%;">42</dd>
  <dd class="widget-metric-detail">Optional units or detail</dd>
</dl>

Choose widget-metric-value--short for tall short values (text-4xl) or widget-metric-value--long for compact long values (text-lg). The default is text-2xl. Callers choose after formatting; CSS does not count digits or guarantee a single-line fit. Explicit hooks override these defaults.

Width means glyph width when the font supports its registered width axis, never widget columns. Static fonts remain readable. Long values wrap without clipping or hiding digits. No font is selected or downloaded.

.font-metric keeps the family expression matching Baseplate's var(--font-metric, var(--font-body, sans-serif)), sans-serif contract. Its optional --font-metric-size and --font-metric-width hooks provide initial value settings; widget-specific size/width hooks take precedence. Unset settings preserve the underlying styles through revert-layer. Labels, units, descriptions and ordinary numbers keep their typography. Callers supply locale, formatted values and units.

Keep size/weight utilities off hook-controlled values: the utilities layer intentionally wins over component hooks. .font-metric and .tnum remain compatible.

Use dd.widget-metric-status for missing, denied or unavailable values; omit the prominent-value and font classes. A known zero stays 0.

Chart data, progress and video

table.widget-table keeps compact native columns, ordinary type and single quiet row separators at narrow sizes. Keep captions and header scopes; replace table--lined on chart fallback tables.

Use the existing progress height hook for thin card progress: style="--progress-height: var(--line-025)". The default is line-05; progress-bar--thick uses line-1. Fill/background, status and timeline variations remain caller choices.

A video uses the existing .embed inside the content slot. Use a descriptive iframe title and a direct-video link when embedding is unavailable. The YouTube examples show narrow/wide output with autoplay disabled. YouTube needs at least 200px in both dimensions; narrower hosts should show the direct-link state.

<div class="widget-content">
  <div class="embed" style="min-block-size: 200px;">
    <iframe class="block border-0"
      src="https://www.youtube.com/embed/M7lc1UVf-VE?autoplay=0"
      title="YouTube embedded-player demonstration" loading="lazy"
      referrerpolicy="strict-origin-when-cross-origin"
      allow="encrypted-media; picture-in-picture" allowfullscreen
      style="min-block-size: 200px;"></iframe>
  </div>
</div>
