Icon picker

Choose one Phosphor icon for a space, circle or document.

Full set

Select the icon to open the picker. The current icon is selected, search matches names and tags (try “home” or “money”), and arrow keys move across the grid. Choosing an icon closes the picker. Remove clears the value.

Contract

Value
The checked radio submits a Phosphor name such as users-three. Remove submits an empty value.
Subsets
Render only the allowed icons, chosen by name list, Phosphor category or exclusions. Validate the submitted name on the server against the same list.
Icons
Tiles reference /icons/phosphor-bold.svg, generated with npm run icons from @phosphor-icons/core. /icons/phosphor-catalog.json lists each name’s category and search tags.
Without JavaScript
The trigger opens the native popover and the radios submit with the form. Search, Recent and the count stay hidden, and the trigger updates after saving.
Script
createIconPicker({ root, recent, recentKey, recentLimit }) returns refresh() and dispose(). Recent is stored in localStorage. Saving belongs to your application.
