What to exercise

  • Use keyboard staging: focus a handle, press Space, use arrow keys, then Space to request or Escape to cancel.
  • Drag a handle with a pointer or touch input. The component marks a destination but leaves authoritative order unchanged.
  • Choose accept or reject before requesting a move. Try an unrelated update while pending; only the matching explicit result clears pending state.
  • Start a delayed move, remove and reinsert List A, then wait. Its old response must not reorder the reconnected list.
  • During a delayed accepted move, move focus to the external button. The result must not steal focus back into the replaced list.
  • Use both lists to confirm pending state and result IDs remain isolated. Try the nested link and a narrow viewport.
  • On a touch device, drag the handle. With reduced motion enabled, check that the source and destination cues remain visible without movement animation.

Network delay is simulated. The fixture records adapter-listener duration separately from the response timer, then records markup/result handling and a two-frame observation. It does not measure the component’s input handler or guarantee paint timing; formal handler and paint measurements remain pending the maintained browser target.

Update contract

The consumer owns authorization, persistence, ordering and retries. It handles sortable-move-request, applies the authoritative server response, then calls resolveMove with the same request ID. The fixture represents the delayed response as a separate fixture-sse-update event and checks connection generation and request ID before replacing any list markup. Unrelated patches do not acknowledge requests.

HTML hooks are data-sortable-list, data-sortable-item, data-item-id, data-sortable-handle, data-sortable-move and data-sortable-status. CSS marks staged sources and targets with data-sortable-source and data-sortable-target, and pending state on the custom element. Disconnect cancels transient interaction and invalidates its pending ID; reinsertion installs one listener set.
