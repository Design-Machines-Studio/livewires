Dropdown

Toggleable overlay menus for actions and navigation.

Basic dropdown

Toggle via data-open attribute on the container.

Code

<div class="dropdown" data-open>
  <button class="button trigger">Menu</button>
  <ul class="menu">
    <li><a href="#">Action 1</a></li>
    <li><a href="#">Action 2</a></li>
    <li><hr></li>
    <li><button>Delete</button></li>
  </ul>
</div>

Menu dividers

Use <hr> inside list items to separate groups of actions.

Code

<ul class="menu">
  <li><a href="#">View</a></li>
  <li><a href="#">Edit</a></li>
  <li><hr></li>
  <li><a href="#" disabled>Unavailable</a></li>
</ul>

Code

Filter panel

Add .dropdown--panel for a wider content panel instead of a list of actions. The panel is a scrollable .dropdown-body between an optional sticky <header> and <footer>. Built on native <details>/<summary>, so it opens and closes without JavaScript. Add .dropdown-chevron to the trigger icon to flip it while open.

Code

<details class="dropdown dropdown--panel">
  <summary class="trigger button button--small">
    <span>Circles</span>
    <span class="text-muted ml-025">All</span>
    <svg class="icon dropdown-chevron" aria-hidden="true">...</svg>
  </summary>
  <div class="menu">
    <div class="dropdown-body stack stack-compact px-05 py-025"
         role="group" aria-label="Filter by circle">
      <label class="checkbox">
        <input type="checkbox" name="circle" value="design">
        <span>Design</span>
        <span class="text-muted">12<span class="visually-hidden"> members</span></span>
      </label>
    </div>
    <footer class="cluster pt-025 pb-0">
      <button type="button" class="button button--small">Clear all</button>
    </footer>
  </div>
</details>
