Remote search

The application answers a query event. This portable example simulates a remote window over public timezone choices; Baseplate has no new search endpoint or rollout here. This second control submits to the same form through its native form attribute.

Type two characters. “pa” takes 900ms; “par” takes 100ms. Type “fail” for a failed search or “zz” for no results.

Optional module contract

Code

<div class="field" data-combobox>
  <label for="zone">Timezone override</label>
  <select id="zone" name="interface_timezone">
    <option value="" selected>Use organization default</option>
    <option value="Asia/Makassar">Asia/Makassar</option>
  </select>
</div>

import { createCombobox } from '/dist/combobox.js';
const control = createCombobox({ root, mode: 'remote' });
root.addEventListener('combobox-query', ({ detail }) => {
  // Application owns fetching, authorization and filtering.
  // Answer with the same contextId, requestId and query.
  control.applyResults({ ...detail, items: [{ value: 'UTC', label: 'UTC' }] });
});
// Or dispatch combobox-results on root with the same result detail.
// A rejected saved value is a native form validation error:
select.setCustomValidity('The application rejected this value.');
control.refresh();
// Dispose before replacing the whole root; in-place options can refresh.
control.dispose();
Local defaults
No minimum, no debounce; accent-insensitive matching of labels/values.
Remote defaults
Two trimmed Unicode code points, 250ms debounce; trimmed Unicode query, not case- or accent-folded.
Results
combobox-results detail: {contextId, requestId, query, items, error?}. Items: unique string value, string label, optional boolean disabled. At most 50 displayed by default.
Selection
Arrow navigation highlights; Enter or a tap commits. Escape restores the selected label. Native select input/change events are emitted on commitment; combobox-change carries {name,value,label}. Search results never confirm a save.
Form guarantees
One native select owns the submitted name/value, required/custom validity, disabled fieldsets, form association and reset default. The editable input has no name. No formdata shim or hidden input is used.
